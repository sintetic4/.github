**O sistema completo para criar influencers de IA hiper-realistas.**

## Como funciona

```text
prompt ─► persona ─► rosto travado ─► bíblia visual ─► fotos ─► roteiros ─► calendário
                                                                     │
                                  vídeo (beta) no gerador que você conectar ◄┘
```

| | |
|---|---|
| **Rosto travado** | O mesmo influencer em toda foto. Nada de rosto novo a cada imagem. |
| **Bíblia visual** | Perfil, corpo, busto e expressões. A identidade inteira, guardada. |
| **Roteiros e calendário** | Do gancho ao planejamento da semana. |
| **Clone** | Quer ser o rosto sem gravar? 3 a 8 fotos suas bastam. |
| **Seu gerador de vídeo** *(beta)* | A Sintética entrega o texto da fala e a cena. O vídeo sai no gerador que você conectar, com seus créditos. |

## Perguntas frequentes

**O que é a Sintética?**
Um app dentro do ChatGPT *(beta)* que cria influencers de IA com rosto fixo, fotos, roteiros e calendário. O vídeo *(beta)* sai no seu gerador.

**Tem cara de IA?**
Foi feita pra parecer natural: luz natural, selfie, pele com textura. E leva o rótulo de IA.

**Quanto custa?**
